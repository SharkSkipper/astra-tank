# Reference archive

Keep downloaded reference files unchanged. Do not crop, paint over, or replace a source file in place.

`reference-index.csv` is the authoritative ledger. The model manifests use stable IDs such as `QJ-side` and `CR400AF-bogie`; the current CSV rows can be mapped to those IDs by their local file names. Each image must have:

- source page URL and direct image URL;
- author or organization;
- license and license URL;
- access date and local SHA-256;
- view type and modeling use;
- the train/component it supports.

The current seed set uses Wikimedia Commons images for QJ 2655 and CR400AF. It is a photo-led reference set; add official drawings or dimensioned diagrams before making any engineering claim.
