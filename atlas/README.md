# ASTRA ATLAS · 豹 2 模型图谱

以本项目已有的豹 2 早期原型模型制作的浏览器三维查看器。深色界面、中文结构树与参数面板；支持电脑、平板和手机。

## 启动

需要 Node.js 20.19+ 或 22.12+。在本目录执行：

```powershell
npm ci
npm run build
node scripts/serve.mjs
```

默认地址为 `http://localhost:4173/`；端口占用时自动使用下一个端口。也可执行 `powershell -ExecutionPolicy Bypass -File .\start.ps1` 后台启动。`server.log` 记录实际地址。

开发模式：`npm run dev -- --port 4173`。

## 操作

- 拖动模型旋转，滚轮或双指缩放，右键拖动平移。
- 在结构树或模型上选择总成、单个零件；搜索支持中文名称和原始零件 ID。
- 眼睛按钮控制可见性；“单独查看”再次点击后恢复之前的可见状态。
- 分解滑块 0% 为装配；0–45% 按总成展开；45–100% 逐渐排列到零件平铺。平铺采用正交视图并支持平移、缩放。
- 实体、分组色、透视和线框模式；不透明度作用于选中对象，无选择时作用于所有部件。
- 机械姿态支持炮塔回转和炮管俯仰。剖切支持 X/Y/Z 轴、位置和方向调整。
- 导出有选择时仅包含选中的可见零件或总成，无选择时包含全部可见零件；导出当前零件姿态，保留原材质。截图导出三维视窗 PNG。
- 手机通过模型标题右侧按钮打开结构和参数面板。

## 静态部署

`dist/` 是完整静态站点，包含 HTML、JavaScript、CSS、GLB 和第三方许可，无需后端、数据库或 API 密钥。把 `dist/` 的内容上传到任意静态网站目录即可。使用相对资源路径，支持根目录或子目录部署。

Vercel / Netlify 等平台的项目根目录设为 `atlas`，构建命令设为 `npm run build`，输出目录设为 `dist`。静态部署压缩包的根目录已经是网站内容，不需要再次构建。

应通过 HTTP/HTTPS 打开网页；直接双击 HTML 的 `file:` 地址受浏览器模块与模型加载限制。

## 模型与边界

原始模型：`../models/leopard2/Leopard_2_early_prototype.glb`。可编辑 Blender 文件仍在原目录。网页资产副本位于 `public/models/leopard2.glb`，包含 1,857 个逻辑零件、2,197 个渲染网格、453,552 个三角面。170 节履带各自的三个材质网格作为同一零件选择、隐藏和导出。

GLB 没有保存三种 Blender 程序材质的颜色；查看器使用 `../scripts/build_leopard2_reference.py` 的对应线性 RGB 值恢复橄榄漆、暗漆和橡胶颜色。材质不包含原来的程序噪声纹理。

这是外观重建模型，原型编号不确定；内部发动机、传动系统与完整乘员舱未建模。剖切只改变显示，不生成封闭的实体切面，也不在导出时切割网格。“分割”指基于已有零件的拆分与独立导出。

## 参考项目与许可

交互参考：https://github.com/ashemag/human-atlas （核验版本 `1c38bf35c254a891200d3cedecfd57abebe83d8d`）。本实现使用原项目的功能构想重新编写查看器和界面，没有使用其人体模型或人体数据。对应功能为：系统显隐、预设、名称与 ID 搜索、选择信息、隔离恢复、分解平铺、相机视角、自动旋转、重置与移动端面板。剖切、机械姿态、渲染模式及导出是本项目附加功能。

Three.js 与 lucide 的许可副本在 `public/licenses/`，构建时一并复制到 `dist/licenses/`。

## 验证

```powershell
npm test
npm run test:e2e
npm run build
```

浏览器测试需要本机 Chrome 和正在运行的本地站点。可通过 `ATLAS_URL` 指定测试网址。`qa/` 保存截图、导出样本与验证报告。
