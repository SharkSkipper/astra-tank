# Mechanical Atlas

## Register

product

## Users and Purpose

Chinese-speaking model viewers inspect the existing editable early Leopard 2 prototype in a browser, select parts, and separate assemblies. The reference interaction set is ashemag/human-atlas.

## Design Principles

Keep the real model visible at entry. Make selection, visibility, and isolation reversible. Use compact, familiar controls with accessible names. Preserve the existing source asset and disclose its historical reconstruction uncertainty in model metadata.

## Visual Direction

The user requests a dark, technical viewing environment. A graphite work surface reduces surrounding brightness during prolonged model inspection; mint selection, neutral text, and distinct system colors carry meaning. Desktop has a structure browser and inspector surrounding an unframed scene; mobile uses dismissible drawers.

## Accessibility

Keyboard-focusable controls, visible focus, native ranges and checkboxes, readable contrast, reduced motion, and touch orbit navigation.
