# 中文旁白初稿

这一次不让 Astra 做一个“像火车的外壳”，而是给它两套真实车辆资料：前进型蒸汽机车和复兴号 CR400AF 动车。

左边是蒸汽机车，右边是动车。它们在两条平行轨道上，用相同的比例、灯光和镜头并行完成。

判断模型是否合格，不只看车头像不像。锅炉、驾驶室、车轮、连杆、煤水车，或者车身、车门、车窗、转向架和受电弓，都必须是可以单独选择和隐藏的部件。

先看 Astra 的第一版结果，再看它能不能依据参考图修复错误。人工修改会单独标出来，不能把人工打磨后的效果说成模型一次生成的能力。

最后，两辆车回到各自轨道，接受同一套旋转、缩放和部件检查。这个测试不能证明工程级精度，但可以看出 Astra 是否能根据真实资料组织一个可编辑的多部件模型，以及它在哪些地方仍然需要人工判断。
