# Capture checklist

- Record the complete Astra screen, including prompts, waits, errors, repairs, save operations, and exports.
- Save the exact prompt before sending it. Use a separate prompt file for QJ and CR400AF.
- Preserve the first unmodified model before repairs.
- Record the Blender version, Astra model/version, operating system, and project file path.
- Log the exact reference IDs used for each part.
- Mark every human intervention with timestamp and reason.
- Capture an Outliner view showing separate component objects.
- Capture isolate/hide/select actions for wheels, bogies, rods, roof equipment, couplers, and body groups.
- Capture an exploded view for both trains.
- Capture the final two-track scene with the same camera and lighting.
- Export GLB only after the component hierarchy passes the checklist.
