# 豹 2 三维模型网页交付

- `ASTRA_ATLAS_web.zip`：已构建的静态网站，解压后将全部内容上传到静态服务器目录即可。
- `ASTRA_ATLAS_source.zip`：完整网页源码、模型、构建文件、测试及本地启动脚本。不含 node_modules。
- 原始可编辑 Blender 模型位于项目 `models/leopard2/`，未被修改。

本机运行地址：`http://localhost:4173/`。

网页已验证 1,857 个独立部件、总成与零件显隐、单独查看与恢复、搜索、爆炸与平铺、剖切、姿态调节、渲染模式、截图及 GLB 导出。完成 3 项数据测试与 11 组浏览器流程检查，覆盖电脑、平板和手机。验证截图和报告在项目 `atlas/qa/`。

模型为外观重建；剖切为显示效果，部件导出不进行实体网格切割或切面封口。详情见源码包中的 README.md。
